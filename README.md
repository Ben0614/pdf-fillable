# PDF - fillable

這是一個使用 Vue 3、Vite、Vuetify、@tato30/vue-pdf、pdf-lib所構建的 PDF 編輯器。

## 功能

- **PDF 上傳**：用戶可以上傳 PDF 文件。
- **互動元素操作**：支持對 PDF 中的互動元素（如 input、select 等）進行輸入或選取。
- **圖片上傳與編輯**：用戶可以上傳圖片，並調整圖片在 PDF 中的位置和大小。
- **PDF 下載**：將編輯後的 PDF 文件下載到本地。

## 技術棧

- **Vue 3**
- **Vite**
- **Vuetify**
- **@tato30/vue-pdf**
- **pdf-lib**
